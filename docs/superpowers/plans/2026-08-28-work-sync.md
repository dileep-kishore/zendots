# Work sync implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify one `work-sync` CLI for safe Syncthing setup and explicit Git and Orca worktree handoffs between macmini and tsuki.

**Architecture:** A uv-managed Typer package reads the private manifest, uses one local-or-SSH command runner, and delegates to Syncthing and handoff modules. Syncthing carries main-checkout files, Git over SSH carries commits and refs, and rsync carries external Orca worktree files without copying `.git`.

**Tech Stack:** Python 3.12+, uv, Typer, Rich, pytest, Ruff, ty, Git, rsync, Syncthing CLI, Orca CLI, SSH

**Spec:** `docs/superpowers/specs/2026-08-28-work-sync-design.md`

## Global constraints

- Never copy `.git`, Git lock files, ownership, groups, or extended attributes.
- Preserve executable status with rsync's executability support.
- Abort all selected repositories before mutation if any preflight fails.
- Never delete target-only branches or force-update divergent branches.
- Never edit project `.gitignore` files.
- Keep `private_dot_config/work-sync/folders.json` synced through Syncthing and ignored by Git only.
- Leave DataLake, TraitWeaver, and every repository absent from the manifest untouched.
- Leave `/Volumes/SSK SSD/Backup-2026-08-20` untouched.
- Stage and commit only files named in each task.
